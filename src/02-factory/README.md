¿Qué problema resuelve Factory?
Factory sirve para crear objetos de una forma más organizada, sin tener que hacerlo  en todas partes del programa.

¿Qué ventaja tiene respecto a utilizar new directamente por toda la aplicación?
Que no tenemos que poner new por todo el programa. La creación de los objetos está más ordenada.

¿Qué tendría que ocurrir si mañana añadimos WhatsAppNotification?
Solo tendríamos que añadir el nuevo tipo en la Factory y no cambiar todas las partes del programa.

¿Quién tiene la responsabilidad de crear los objetos?
La responsabilidad la tiene la Factory, que es la encargada de crear el objeto que necesitamos.

¿Qué ventaja proporciona Factory respecto al acoplamiento?
Hace que las partes del programa estén menos unidas entre sí, por lo que es más fácil cambiar una cosa sin tener que modificar muchas otras.
