¿Qué problema intenta resolver Singleton?
Singleton sirve para que de una clase solo haya un objeto y no se puedan crear muchos.

¿Por qué suele utilizarse un constructor private?
Para que no se pueda hacer new y crear objetos como quieras.

¿Cómo se obtiene una instancia de la clase?
Se obtiene con un método llamado getInstance(), que te devuelve objeto que existe.

¿Qué ocurriría si pudiéramos utilizar new libremente?
Se podrían crear varios objetos de la misma clase y entonces ya no sería un Singleton.

Pon un ejemplo real donde utilizarías Singleton.
Por ejemplo, una fabrica de magdalenas para tener un unico codigo que cree varias y no creas varias que hagan lo mismo

¿Qué inconveniente puede tener abusar de Singleton?
Que si lo usamos para todo, el programa sera más difícil de entender y modificar.
