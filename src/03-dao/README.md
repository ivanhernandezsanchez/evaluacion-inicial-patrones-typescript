¿Qué significa DAO?
DAO significa Data Access Object, que es un objeto que se encarga de acceder a los datos.

¿Cuál es su responsabilidad principal?
Su función principal es guardar, buscar, modificar y borrar datos.

¿Qué relación tiene DAO con una base de datos?
El DAO es el que se encarga de hablar con la base de datos para obtener o guardar información.

¿Qué operaciones aparecen habitualmente en un DAO?
Normalmente aparecen operaciones como:

Crear datos,buscar datos,modificar datos,borrar datos.

¿Qué diferencia existe entre DAO y Repository?
Los dos sirven para trabajar con datos, pero el DAO suele estar más relacionado con la base de datos, mientras que el Repository suele estar más relacionado con la lógica de la aplicación.
